How to run (REQUIRES PYTHON 3.11):

1. py -3.11 -m venv .venv
2. .\.venv\Scripts\Activate.ps1
3. python -m pip install --upgrade pip
4. python -m pip install -r requirements.txt
5. python -m pip install TTS sounddevice
6. python tts_cli_player_basic.py (can use the v2 one for clearer dialogue, save one for it to save directly)
